## 🚀 Deploy lên Render

### Cách 1: Render.com (Khuyến nghị)

1. Push code lên GitHub
2. Vào [render.com](https://render.com) → Sign up
3. Click **New +** → **Static Site**
4. Connect GitHub repo `bck-profile`
5. Cấu hình:
   - **Name**: `bck-profile`
   - **Branch**: `main`
   - **Publish Directory**: `.` (root)
6. Click **Create Static Site**
7. Đợi 1-2 phút → Có link `https://bck-profile.onrender.com`

### Cách 2: Netlify Drop (Nhanh nhất)

1. Vào [app.netlify.com/drop](https://app.netlify.com/drop)
2. Kéo thả folder `profile` vào
3. Có link ngay trong 10 giây!

### Cách 3: Vercel

1. Vào [vercel.com](https://vercel.com) → Sign up
2. **Add New Project** → Import GitHub repo
3. Click **Deploy**
4. Có link `https://bck-profile.vercel.app`

### Cách 4: GitHub Pages

1. Vào repo **Settings** → **Pages**
2. Source: **Deploy from a branch** → `main` / `root`
3. Save → Có link `https://username.github.io/bck-profile`
